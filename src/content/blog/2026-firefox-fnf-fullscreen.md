前两天早上收到订阅的 Firefox 的ticket: [Support fn+f as fullscreen shortcut on macOS](https://bugzilla.mozilla.org/show_bug.cgi?id=1748950),
看名字这个也是一个中国人提的，4年前了，我也在1年前评论过然后就没人理了，前两天突然assign给一个人
然后一两天就做完了，今天在nightly版本中已经体验到了。舒服了，因为所有的软件都是支持的，
只有 Firefox 要单独记很麻烦。

不过现在还有两个软件没解决这个问题：VS Code 和 Emacs
